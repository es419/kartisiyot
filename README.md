# כרטיסיות

אפליקציית לימוד (PWA) בסגנון Quizlet, עם יומן למידה לעבודה. React + TypeScript + Vite + Supabase.

## הרצה

1. **Supabase**: ב-SQL Editor הרץ את `supabase/schema.sql`. אם כבר הרצת גרסה קודמת, הרץ רק את מה שחסר: `migration_v2.sql` (FSRS ותאריך מבחן), ואז `migration_v3.sql` (סטים ציבוריים ותרשימים), ואז `migration_v4.sql` (רמת בדיקת תשובות ותשובות נוספות לכרטיסייה). כל הטבלאות עם הקידומת `fc_`.
2. **סביבה**: העתק `.env.example` ל-`.env` ומלא כתובת פרויקט (בלי `/rest/v1/`) ומפתח publishable.
3. `npm install` ואז `npm run dev`.

## פריסה ל-iPhone

1. `npm run build`, ופרוס את `dist` ל-Netlify (או Vercel/Cloudflare Pages). הוסף את שני משתני הסביבה בהגדרות האתר.
2. פתח את הכתובת ב-Safari, שיתוף, "הוסף למסך הבית".

## מה יש בפנים

- סטים ותיקיות, חיפוש בסטים ובכל הכרטיסיות, כוכב, סידור, שכפול והעברה בין סטים
- **למידה**: כרטיסיות, למידה (FSRS), כתיבה, איות (שמע והקלד), מבחן, האזנה
- **משחקים**: התאמה, כבידה, פיצוץ, בלוקים, וחידון חי מרובה משתתפים (שחקנים נכנסים עם קוד מהטלפון)
- **תרשימים אינטראקטיביים**: מעלים תמונה או מפה, מסמנים נקודות עם שמות, ומתרגלים ("מה זה?" ו"איפה?")
- **סטים ציבוריים**: בעריכת סט בוחרים שיתוף "ציבורי", והוא מופיע ב"גלה סטים ציבוריים"
- כרטיסיות השלמה (`{{מילה}}`), נוסחאות (`$x^2$`), תמונות, הקראה, ייבוא וייצוא
- חזרה יומית, יעד יומי, רצף, מפת חום, תאריך מבחן עם תכנון
- יומן למידה: סוגי רשומות, תגיות, שאלות פתוחות, סיכום שבועי, הפיכה לכרטיסייה
- **בדיקת תשובות מוקלדות**: לכל סט רמה משלו, מדויק, גמיש (ברירת מחדל, בלי AI: סדר מילים, אותיות שימוש, ריבוי וטעויות הקלדה) או חכם (AI לפי משמעות). אפשר להגדיר לכל כרטיסייה גם תשובות נוספות שמתקבלות
- **AI** (צריך פריסה של פונקציה, ראה למטה): כרטיסיות מחומר או PDF, בדיקת תשובות לפי משמעות (ברמה "חכם" בסט), מבחן AI עם שאלות חדשות, מדריך לימוד, ופותר שאלות עם הסבר שלב אחר שלב (גם מתמונה)

## AI: פריסה חד-פעמית

כל תכונות ה-AI רצות בפונקציה אחת, `fc-magic`. היא דורשת מפתח API של Anthropic (עלות של אגורות עד כמה סנטים לפעולה) ו-Supabase CLI:

```
npx supabase login
npx supabase link --project-ref YOUR-PROJECT-REF
npx supabase secrets set ANTHROPIC_API_KEY=sk-ant-...
npx supabase functions deploy fc-magic --use-api
```

אם כבר פרסת אותה בעבר, הרץ שוב רק את שורת ה-`deploy`. הפונקציה מוגבלת למשתמשים מחוברים. הפותר משתמש במודל חזק יותר ולכן יקר יותר. אל תעלה חומר פנימי או רגיש מהעבודה לכלי חיצוני.

## חידון חי

המשחק רץ על Supabase Realtime. אם שחקנים לא מופיעים בלובי, ב-Supabase: Realtime, Settings, הפעל את Allow public access.

## לא נכלל

פתרונות מספרי לימוד מורשים (הפותר הוא AI ולא תוכן של ספר), דירוג קבוצות בחידון החי (הניקוד אישי), והתראות פוש כשהאפליקציה סגורה (מוגבל ב-PWA באייפון).
