# כרטיסיות

אפליקציית לימוד (PWA) בסגנון Quizlet, עם יומן למידה לעבודה. React + TypeScript + Vite + Supabase.

## הרצה

1. **Supabase**: ב-SQL Editor הרץ את `supabase/schema.sql`. אם כבר הרצת גרסה קודמת, הרץ במקום זה רק את `supabase/migration_v2.sql` (מוסיף FSRS ותאריך מבחן). כל הטבלאות עם הקידומת `fc_`.
2. **סביבה**: העתק `.env.example` ל-`.env` ומלא כתובת פרויקט (בלי `/rest/v1/`) ומפתח publishable.
3. `npm install` ואז `npm run dev`.

## פריסה ל-iPhone

1. `npm run build`, ופרוס את `dist` ל-Netlify (או Vercel/Cloudflare Pages). הוסף את שני משתני הסביבה בהגדרות האתר.
2. פתח את הכתובת ב-Safari, שיתוף, "הוסף למסך הבית".

## מה יש בפנים

- סטים ותיקיות, חיפוש בסטים ובכל הכרטיסיות, כוכב, סידור, שכפול והעברה בין סטים
- כרטיסיות, למידה (FSRS), כתיבה, מבחן, התאמה, כבידה, האזנה
- כרטיסיות השלמה: סמן מילים בעורך ולחץ "חור", או כתוב `{{מילה}}`
- נוסחאות (LaTeX): `$x^2$` בתוך שורה, `$$...$$` כבלוק
- חזרה יומית מכל הסטים, יעד יומי, רצף, מפת חום, סטטיסטיקה
- תאריך מבחן לסט: האפליקציה מחשבת כמה כרטיסיות חדשות ללמוד כל יום
- ייבוא מטקסט או מאקסל, ייצוא, תמונות, הקראה, שיתוף בקישור
- יומן למידה: סוגי רשומות, תגיות, שאלות פתוחות, סיכום שבועי, הפיכה לכרטיסייה

## אופציונלי: יצירת כרטיסיות עם AI

דורש מפתח API של Anthropic (עלות של אגורות לכל יצירה) ו-Supabase CLI:

```
supabase login
supabase link --project-ref YOUR-PROJECT-REF
supabase secrets set ANTHROPIC_API_KEY=sk-ant-...
supabase functions deploy fc-magic
```

אחרי הפריסה, בחלון "ייבוא" יעבוד הטאב "יצירה עם AI". הפונקציה מוגבלת למשתמשים מחוברים.
אל תעלה חומר פנימי או רגיש מהעבודה לכלי חיצוני.
